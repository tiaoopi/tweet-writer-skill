# 推文写作参考：钩子、口语、表情、正反例

## 一、开头"诱惑性问题"句式模板

目标：让人**想回答、想反驳、想看下文**。常用套路：

| 类型 | 模板 | 例 |
|---|---|---|
| 反常识反问 | 你以为 X 是因为 Y？真的吗？ | 年轻人负债越来越多，真怪他们不会攒钱吗？🤔 |
| 打脸预告 | XX 到底有多离谱，你知道吗？ | 你猜一个人能蠢到什么程度？ |
| 站队挑衅 | 这事你站谁？ | 老板这么做，你说是他黑还是员工惨？ |
| 悬念数字 | 月入 X 的人，背了多少债？ | 月入 1 万，负债 115 万，你敢信？ |
| 直接喊话 | 还有谁觉得 X？站出来 | 谁还在信"只要努力就能翻身"？ |

写好后自检：**这句问题，别人看了会不会手痒想评论？** 不会就重写。

## 二、口语词库（接地气，替代书面腔）

- 称呼：这哥们 / 老哥 / 那姑娘 / 我有个朋友 / 有个律师 / 一网友
- 递进：结果呢 / 你猜怎么着 / 更绝的是 / 最扎心的是 / 好家伙
- 态度：真服了 / 我是真没想到 / 说实话 / 说白了 / 离谱 / 绷不住了
- 收尾：就…… / 你自己品 / 反正我是看麻了 / 只能说，好自为之

**替换表（书面 → 口语）：**

| 不要写 | 改成 |
|---|---|
| 该现象反映了… | 说白了就是… |
| 由此可见 | 结果呢 |
| 令人震惊 | 我人傻了 / 绷不住 |
| 存在较大风险 | 一不小心就踩坑 |

## 三、推特常用表情库（克制使用，1~3 个）

- 思考/反问：🤔
- 震惊/离谱：😮💨 😅 😂 绷
- 扎心/无奈：😭 💔 🫠
- 钱/经济：💸 💰 📉
- 强调/引导：👇 🧵 🔥 ✨
- 通用结尾：🚬 🍵 😶

**避免**：一长串连发、冷门 emoji、花哨装饰性符号（★☆~ 等）。

## 四、正反例对照

**❌ 反例（AI 腔、书面、无钩子、不换行）：**
> 当前年轻人负债问题日益严重，主要原因是消费观念转变、信贷便利及缺乏财务规划意识，建议树立正确的消费观。

问题：无诱惑性提问、书面腔、没换行、没表情、不具体。

**✅ 正例（≤100 字）：**
> 年轻人负债越来越多，真怪他们不会攒钱吗？🤔
>
> 一个律师晒出几十个真实案子：借身份证当股东、帮好兄弟担保、中介卷租跑路、网贷以贷养贷……
>
> 最惨那哥们是个公务员，月入 1 万，欠了 115 万，天天拆东墙补西墙💸

好在：开头勾人、口语唠嗑感、有换行呼吸感、具体到人和数字、表情克制。

## 五、钱味选题角度（最高优先级）

推特中文区最爱读"和钱有关"的话题，尤其**搞钱 / 亏钱 / 被坑**。焦虑感 = 点击率。常用切入角度：

- **别人怎么赚的**：副业、信息差、新风口、白手起家路径
- **普通人怎么亏的**：负债、割韭菜、投资暴雷、法律陷阱、被骗
- **收入 vs 现实的落差**：月入 X 却欠 Y、越打工越穷、房贷车贷压死人
- **反常识金钱真相**：让人想反驳、想留言的那种说法

**焦虑型钩子示例**：
> 你以为只要老实上班，就不会缺钱？🤔
> 一个 92 年的哥们，月入 1 万，负债 115 万……
> 到底哪一步走错了？👇

**素材不带钱味时**：找一个跟"利益 / 收入 / 损失 / 被坑"相关的切面来写，别硬扯。

### 红线（尽量少讨论）

- ⚠️ **政治尽量少碰**：不涉政治、体制、权力斗争；绕不开就中性陈述、不站队、不引申。
- ⚠️ **色情尽量少碰**：不写软色情、不擦边；两性话题只谈"钱 / 法律 / 利益"层面的客观事实。
- 推文曝光高的三要素是 钱/权/性，但**只有"钱"是主推、可以放开写**，后两者是底线、尽量少讨论。
- 一句话：**政治、色情尽量少碰；话题只要沾钱，就往钱上多写。**

## 六、收尾标签（可选，默认不带）+ 索要互动禁令

### ⛔ 第一优先：禁止索要互动

下面这些话术**一个字都不要出现**在推文里：

> 扣 1 / 评论区报个数 / 我去你主页回访 / 逛后感发你评论区 / 条条必回 / 互赞互回 / 关注我 / 求转发 / 看到必回

原因：X 把这类内容判为 **spam / 平台操纵（artificially amplify engagement）**，后果是给账号打"临时标签"——**触达被排除出推荐、搜索、回复区、趋势**，等于只发给现有粉丝看。（真实教训：账号已因这类行为被打过标签。）

**替代做法**：把"要人回"换成"让人想回"——
- ❌ 评论区扣"交个朋友"，我条条必回
- ✅ 你们觉得这套玩法还能撑多久？（问题本身有争议，自然有人接）

### 标签：可选、默认不带

默认**不输出**标签行。仅当用户明确要求带标签时，才挑 **1 个**（别每条都带、别总用同一个）：

| 系别 | 备用标签 |
|---|---|
| 蓝V系 | `#蓝V互关` `#蓝V互助` `#蓝V交朋友` |
| 内容系 | `#AI搞钱` `#AI工具` `#程序员日常` `#搞钱思路` `#职场观察` `#副业笔记` |
| 交友系 | `#真诚交友` `#浇朋友` |

⛔ **已停用**（风控特征词，一律不用）：`#互关必回` `#互赞互关` `#互关互助` `#涨粉互助` `#互关走一波` `#抱团互助`

标签行不占正文字数。

## 七、收尾自检清单

- [ ] 是否先读了原文？有没有编造？
- [ ] 全文 ≤ 100 字？（数一遍）
- [ ] 第一行是不是一句勾人的问题？
- [ ] 有没有至少 2~3 段、有换行？
- [ ] 语气像不像在跟朋友唠嗑？
- [ ] 表情是否 1~3 个、够大众？
- [ ] 是否只讲了**一个**核心点？
- [ ] **话题能沾钱时，是否优先往"钱"上多写？**
- [ ] **是否尽量少讨论政治与色情？**
- [ ] 有没有"扣 1 / 必回 / 求关注 / 求转发"这类**索要互动**的话术？（有就删干净）
- [ ] 标签是否**默认没带**（只在用户明确要求时才带 1 个）？
