# Tweet Writer（中文推特短推文写作）

## Overview

把长内容或一个观点，压缩成一条**不超过 100 字**的中文推文。核心不是"浓缩信息"，而是**用一句勾人的问题当钩子，用唠嗑的语气讲一个具体的点，让人想读完、想回复**。

## 何时使用

- 用户给一篇文章/链接/素材，要求"写成推文"
- 用户给一个话题或观点，要求输出适合发推特/X 的短文案
- 用户明确提到"接地气""像唠嗑""150字以内/100字以内""带表情"

## 硬性规则（必须全部满足）

1. **先读原文**：若用户提供了文章、链接或附件，**必须先完整读取内容**，再动笔。禁止未读就写，禁止编造原文没有的事实、数字、案例。
2. **字数 ≤ 100 字**：统计中文汉字 + 数字 + 标点（表情符号不强制计入，但整体要短）。写完必须自己数一遍，超出就删到 100 字以内。宁短勿长。
3. **开头是一句"诱惑性问题"**：第一行用一句反问/设问，**让人觉得"这我有话说/我想反驳/我想知道答案"**，从而点进来读完。问题要带一点反常识或悬念，不能是平淡的陈述句。
4. **语气接地气、真实**：像跟朋友唠嗑，用口语词（"这哥们""真服了""说实话""结果呢"），拒绝书面腔、宣传腔、AI 腔。可以带一点个人态度和情绪。
5. **排版有呼吸感**：至少 2~3 段，段间换行；每行别太长，手机上要一眼扫得完。长句拆成短句。
6. **表情符合推特大众习惯**：用推特上常见、克制的那几个（🤔 😂 😅 😮💨 💸 🧵 👇 🔥 😭 …），一般 1~3 个，放在句尾或行尾，**不要堆砌、不要用冷门或花哨表情**。
7. **只讲一个核心点**：≤100 字塞不下所有信息，挑最扎心/最反直觉的那一点放大，其余果断舍弃。
8. **选题守红线、优先谈钱**：**尽量少讨论政治、色情**；只要话题能跟钱挂上钩，就尽量多写和钱有关的内容。详见下方《选题优先级与内容红线》。
9. **互关标签收尾（铁律，但必须换花样）**：正文写完后，**必须另起一行**附互关/交友类话题标签收尾，一般 1~2 个。**禁止每条都固定用同一组**——按内容气质从下方"标签池"里挑，**并尽量与上一条不同**，别让所有推文结尾长得一模一样：

| 系别 | 可选标签（每个系挑 1 个） |
|---|---|
| 蓝V系 | `#蓝V互关` `#蓝V互关互助` `#蓝V交朋友` `#蓝V互助` `#蓝V互关涨粉` |
| 交友系 | `#真诚交友` `#交个朋友` `#浇朋友` `#互关交友` `#交友互助` |
| 互助系 | `#互关互助` `#互关必回` `#互赞互关` `#报团取暖` `#抱团互助` |
| 起号系 | `#新人起号` `#起号互助` `#涨粉互助` `#冷启动互助` `#互关走一波` |

组合建议：「蓝V系 / 互助系」各挑一个搭配（既表身份又表意愿），两条之间别同质；内容很素时只带 1 个也行。**同一组标签不要连着用两次以上。** **标签行不计入字数限制**，100 字只算正文。

## 选题优先级与内容红线

推文曝光高的三要素是 **钱 / 权 / 性**，但三者待遇完全不同——**只有"钱"是主推方向，后两者是底线、尽量少讨论**：

| 维度 | 处理方式 | 说明 |
|---|---|---|
| 💰 **钱** | **主推、放开写** | 最高优先级。搞钱、副业、收入、负债、被割韭菜、买房/理财踩坑、行业暴富或暴雷……中文区用户最爱读 |
| 👑 权 | **底线，尽量少讨论** | 涉及政治、体制、权力斗争等敏感内容，能绕就绕；必要时只做中性事实陈述，不站队、不引申、不留把柄 |
| 🔞 性 | **底线，尽量少讨论** | 不写色情、擦边、软色情；涉两性话题只做与"钱/法律/利益"相关的客观讨论，不作感官描写 |

> 一句话记住：**政治、色情尽量少碰；话题只要沾钱，就往钱上多写。**

**钱的写法——用"焦虑感"当钩子**：读者读到"搞钱/亏钱"的内容容易焦虑，一焦虑就会点进来、想评论。常用角度：

- 别人怎么赚到的（搞钱路径、信息差、新风口）
- 普通人怎么被坑的（负债、割韭菜、投资暴雷、法律陷阱）
- 收入与现实的落差（月入 X 却欠 Y、打工越打越穷）
- 反常识的金钱真相（让你想反驳的那种）

**红线自检**：写完问自己——①有没有涉及政治/体制敏感点？②有没有擦边色情？只要有一个，整条重写或换角度。

## 工作流程

1. **读素材**：完整读取文章/链接/附件，提取"最戳人的那个具体细节"（一个人、一个数字、一句原话、一个反转）。
2. **定角度**：优先往"钱"上靠（搞钱 / 亏钱 / 负债 / 被坑）。回避政治、色情，后者只做客观中性处理。素材若本身不带钱味，找一个和利益、收入、损失的切面切入。
3. **选钩子**：围绕这个细节，设计一句能勾起好奇或引发讨论的开头提问。
4. **写正文**：用口语把细节讲清楚，制造"反差"或"扎心感"，结尾可留一个耐人寻味的话或半开放结尾。
5. **控字数**：数一遍，超 100 字就砍。优先砍修饰、砍并列、砍重复。
6. **过红线 + 加表情 + 排段**：先按红线自检（无政治、无色情），再按规则 5、6 调整格式。
7. **补标签收尾**：按规则 9，正文后另起一行加上互关类标签，**并换一组和上次不同的**（从标签池另系里挑）。

## 写作要点

- **钩子模板**（任选、改写）：见 `references/tweet-patterns.md`
- **反差结构**：先给一个常见认知，再用素材里的真实细节打脸（"你以为…结果…"）
- **具体 > 抽象**：写"月入 1 万欠了 115 万"，不要写"负债问题严重"
- **口语词库 / 表情库 / 正反例**：见 `references/tweet-patterns.md`
