# 抓取与提取参考：公众号链接处理 + 剔杂质

## 一、公众号链接抓取

### 常见链接形态（都是正常页面，直接抓）

```
https://mp.weixin.qq.com/s/XXXXXXXX
https://mp.weixin.qq.com/s?__biz=...&mid=...&idx=...&sn=...
```

### 抓取步骤

1. **首选** `WebFetch`，prompt 写明"提取文章标题和完整正文文字"。
2. 若返回内容过短/被截断，或有跳转，**按其提示用重定向 URL 再抓一次**。
3. 若页面提示需登录、已被删除、或正文全是图片，抓取会失败 → 换用浏览器抓取工具打开页面取正文。
4. **全部失败**：如实告知用户"这篇抓不到正文（原因）"，请其把正文文字粘贴过来。**禁止脑补编造。**

### 要拿到什么（提取清单）

| 类别 | 提取内容 |
|---|---|
| 标题 | 文章主标题（做封面贴图主标题的素材） |
| 正文 | 段落主体文字，按顺序读全 |
| 数字 | 金额、数量、百分比、日期、涨跌幅 |
| 人物 | 谁、什么身份、做了什么 |
| 关键句 | 作者的原话、金句、结论 |
| 反转/冲突 | 事情出乎意料的地方 |

### 要忽略什么

导航栏、推荐阅读、"点击上方关注"、页脚二维码、历史文章列表、广告位。

## 二、剔除杂质规则（核心）

只保留**文章本身的干货**；以下四类**一律剔除**，不写进贴图与文案：

| 类型 | 识别特征 | 处理 |
|---|---|---|
| 🚫 私人宣传 | "关注我""我是 XX""我的项目/社群/课程""赞赏支持" | 剔除 |
| 🚫 付费推广 | 付费课程、付费专栏、训练营、付费咨询、报名入口 | 剔除 |
| 🚫 带货 | 商品链接、优惠券、团购、限时折扣、带货话术 | 剔除 |
| 🚫 引流吸粉 | 加微信、扫码进群、领取资料、涨粉引导 | 剔除 |

**一句话判断**：这段内容是**"文章要讲的知识/事实/观点"**，还是**"作者想从读者身上获利"**？后者剔除。

## 三、从正文提炼"点"

提炼出 **1~5 个**最值得做成贴图的点。好点的特征：

- 有**具体数字**（"月入 1 万却欠 115 万" > "负债严重"）
- 有**反差**（你以为 A，结果 B）
- 有**原话/金句**（作者一句扎心的总结）
- 有**结论/方法**（可操作的干货）

排序：把**最扎心/最反直觉**的那个点放第 1 张（封面），其余按重要度排。

## 四、角度优先：能沾钱就写钱

小程序、微信、小红书用户对"和钱有关"的内容最敏感。文章沾钱（搞钱 / 亏钱 / 被坑 / 收益 / 成本 / 副业 / 负债）时，优先把角度往"钱"上靠。

**红线**：政治、色情尽量少讨论。原文若以政治/色情为核心，向用户说明并建议换角度，不硬写。
