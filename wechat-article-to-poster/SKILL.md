# WeChat Article to Poster（公众号文章 → 微信贴图 + 短文案）

## Overview

给一条公众号文章链接，把它**读透**，然后转成一组可直接分发的「贴图」+ 一段短文案。核心是三步：
**抓取正文 → 剔除杂质（私人宣传/付费/带货）→ 拆成低密度图文卡片，每张只说一个点**。

产出的贴图面向**小红书 / 微头条式分发**：单张卡片文字要少、要有呼吸感，一张读不完就拆成多张，绝不把长文硬塞进一张图。

## 何时使用

- 用户给一条公众号链接（`mp.weixin.qq.com/...` 或含 `__biz` 参数），要求"读这篇文章 / 做成贴图 / 转成图文"
- 用户说"公众号转贴图""生成微信贴图""把这篇公众号做成卡片""文章转小红书图文"
- 用户给公众号链接并说"配一段文案"

## 硬性规则（必须全部满足）

1. **必须先读原文**：未抓取并读完整篇公众号正文前，禁止动笔、禁止生成图片。禁止编造原文没有的事实、数字、案例、观点。原文抓取失败（需登录、被删、仅图片）时，如实告知用户并请其提供正文，不得脑补。
2. **剔除三类杂质**：**私人宣传**（作者个人推荐、自我吹捧）、**付费推广**（付费课程/社群/付费专栏硬广）、**带货**（商品/服务/优惠券/团购）——以及一切同性质的引流吸粉、加好友、扫码进群内容，**一律不写进贴图与文案**。只保留文章本身的干货、事实、观点、故事。
3. **贴图文字密度要低**：每张贴图只承载**一个核心点**，文字精炼（建议**主标题 ≤ 16 字、正文要点 ≤ 60 字**），字号大、留白足，一眼扫完。**信息装不下就拆成多张**（一张一个点），严禁把长段落堆进一张图。
4. **拆图数量按内容定**：通常 **1~5 张**。内容少 → 1 张；有多层要点 → 每点一张，形成图组。
5. **短文案 ≤ 200 字**：统计中文汉字 + 数字 + 标点（表情不计但整体要短）。**必须带表情**（小红书/微信大众常用那类），有换行呼吸感，开头抓人。
6. **有钩子**：文案开头用一句勾人的提问/悬念/反差，让人想点开看。
7. **守红线**：**政治、色情尽量少讨论**；话题能沾钱（搞钱/亏钱/被坑/收益/成本）就优先往钱上靠。原文核心若是政治/色情敏感内容，向用户说明并建议换角度，不硬写。

## 工作流程

### 第 1 步：抓取并读完整篇文章

用抓取工具（`WebFetch` / 浏览器抓取 / 用户提供的正文）读取公众号链接，完整拿到**标题 + 正文**。

抓取要点：
- 公众号链接常带 `__biz`、`mid`、`idx`、`sn` 等参数，属正常页面地址，直接抓取即可。
- 优先取**正文主体**（段落文字），忽略导航、推荐阅读、"点击关注"等页脚。
- 正文含大量配图、二维码时，**文字照读，图片与二维码按规则 2 剔除**。
- 抓不到时：换 `WebFetch` 重试；仍失败则请用户直接把正文粘贴过来。

详见 `references/fetch-and-extract.md` 的抓取与提取清单。

### 第 2 步：提炼 + 剔杂质

从全文里抓出**最戳人的 1~5 个点**（一个数字、一句原话、一个反转、一个结论），同时**过滤掉**：

| 剔除项 | 例子 |
|---|---|
| 私人宣传 | "关注我""我是 XX 老师""我做的项目""我的社群" |
| 付费推广 | 付费课程、付费专栏、训练营、付费咨询报名 |
| 带货 | 商品链接、优惠券、团购、限时折扣、带货话术 |
| 引流吸粉 | 加微信/扫码进群/领取资料/关注公众号涨粉 |

> 判断标准：**"这是文章本身的干货，还是作者想从读者身上捞点什么？"** 后者一律剔除。

### 第 3 步：拆成低密度贴图

把提炼出的点，拆成图组，每张一个点：

- **第 1 张 = 封面/主图**：用最扎心的那一点或一句金句做主标题，勾人点进来。
- **后续张 = 每个要点一张**：主标题（≤16 字）+ 2~3 行要点（合计 ≤60 字）。
- 每张只讲一件事；宁可多出一张，也不要挤。

每张图的**图内文字内容**这样组织（交给图像生成能力去渲染）：

```
【主标题】一句话 ≤16 字，大字加粗，抓眼球
【副要点】2~3 行短句，每行 ≤18 字，合计 ≤60 字
【底部】可选：一个 emoji 或极短引导词（如"👇""收藏"）
```

视觉要求（写进生成提示词）：
- **低密度**：大面积留白，文字四周留足边距，绝不顶格堆满。
- 风格：小红书/微头条式**图文卡片**，干净背景 + 一到两种主色，字号大、层级清楚。
- 中文渲染：**生图模型对中文字形易出错**。若模型不能稳定渲染中文，改用"HTML 卡片渲染 → 截图导出 PNG"的方式，保证字形精准（见 `references/poster-prompt-guide.md` 的降级方案）。

### 第 4 步：生成贴图

用图像生成工具（`ImageGen`）按上面的图文内容逐张生成，**每张一个独立文件**。

- 先写清楚每张图的提示词（含风格、配色、留白、文字内容），逐张生成。
- 生成后**逐张核对**：图内中文有没有错字/乱码？文字密度是不是太满？要点是否与原意一致？不合格就重生成或改用 HTML 渲染方案。
- 编号命名，如 `poster-01.png`、`poster-02.png`，方便按顺序发布。

提示词模板与正反例见 `references/poster-prompt-guide.md`。

### 第 5 步：写短文案（≤200 字）

在贴图基础上配一段短文案，规则：

1. **≤200 字**（汉字+数字+标点），表情不计，写完自查。
2. **开头是钩子**：一句提问/悬念/反差，让人想点开图。
3. **接地气、口语化**：像唠嗑，拒绝书面腔、宣传腔、AI 腔。
4. **有换行呼吸感**：2~4 段。
5. **带表情**：1~4 个大众常用表情（🤔 😂 💸 📉 😭 🔥 👇 ✨ …），不堆砌。
6. **同样过红线 + 剔杂质**：不写政治/色情；不写私人宣传、付费推广、带货。

### 第 6 步：交付

- 展示所有贴图 + 文案。
- 交付前用下方自检清单逐项核对。

## 自检清单

- [ ] 文章正文**完整读完**了吗？有没有编造原文没有的信息？
- [ ] 有没有把**私人宣传 / 付费推广 / 带货 / 引流**的内容写进去？（必须为否）
- [ ] 每张贴图是否**只讲一个点**、文字密度够低（主标题 ≤16 字、要点 ≤60 字）？
- [ ] 信息多时，是否**拆成了多张**而不是硬塞？
- [ ] 图内中文有没有错字？渲染是否清晰？
- [ ] 短文案是否 **≤200 字**？
- [ ] 文案开头是不是勾人的钩子？有没有换行、有没有表情？
- [ ] 是否尽量少讨论政治与色情？能沾钱时是否往钱上写？

## 相关技能

- `image-tweet-writer`：读**图片**写推文。
- `tweet-rewriter`：照原文风格仿写推文。
- **本技能**：输入是**公众号文章链接**，输出是**贴图组 + ≤200 字短文案**（图文卡片向）。
