# tweet-writer · 中文推特短推文写作技能

> 把一篇文章、一段素材或一个话题，秒变一条 **≤100 字** 的中文推特推文——开头有勾人的诱惑性提问，语气像唠嗑，排版有呼吸感，自带推特常用表情。

这是一个适用于 **WorkBuddy**（及兼容 Claude Skills 体系）的技能包。装上之后，只要说一句「写推文 / 把这篇写成推文 / 发一条推」，它就会自动按这套风格产出。

---

## ✨ 它能做什么

给它一篇文章、链接或一个观点，产出一条可直接发到推特 / X 的短推文：

- 🎣 **钩子开头**：第一行是一句反问/设问，让人"想反驳、想回答、想读下去"
- 🗣 **接地气**：口语唠嗑感，拒绝书面腔、宣传腔、AI 腔
- 📱 **好排版**：2~3 段换行，手机上一眼扫完
- 😄 **克制表情**：推特大众常用的 1~3 个，不堆砌
- 💰 **谈钱优先**：话题能跟钱沾边，就优先写搞钱 / 亏钱 / 负债 / 被坑
- 🎯 **只讲一点**：掐住最扎心、最反直觉的那一个点放大

## 📋 硬性规则

| # | 规则 |
|---|---|
| 1 | **先读原文**：有文章/链接必须先读，禁止编造事实与数字 |
| 2 | **≤100 字**：写完自查，宁短勿长 |
| 3 | **开头是诱惑性问题**：带反常识或悬念 |
| 4 | **接地气真实**：像跟朋友唠嗑 |
| 5 | **排版有呼吸感**：2~3 段、段间换行 |
| 6 | **表情大众且克制**：1~3 个 |
| 7 | **只讲一个核心点**：其余果断舍弃 |
| 8 | **守红线、优先谈钱**：尽量少讨论政治、色情；沾钱就多写钱 |

### 选题优先级与红线

推文曝光高的三要素是 **钱 / 权 / 性**，但**只有"钱"是主推方向**：

- 💰 **钱**：主推、放开写（搞钱、副业、负债、被割韭菜、理财踩坑……）
- 👑 权：底线，尽量少讨论（不涉政治、体制、权力斗争）
- 🔞 性：底线，尽量少讨论（不写色情、擦边、软色情）

> 一句话：**政治、色情尽量少碰；话题只要沾钱，就往钱上多写。**

## 🚀 安装

### 方式一：手动放置（推荐）

1. 下载 / clone 本仓库：
   ```bash
   git clone https://github.com/<你的用户名>/tweet-writer-skill.git
   ```
2. 把里面的 **`tweet-writer` 文件夹**整个复制到 WorkBuddy 的技能目录：
   - Windows：`C:\Users\<用户名>\.workbuddy\skills\`
   - macOS / Linux：`~/.workbuddy\skills/`
3. 刷新或重启 WorkBuddy，技能即生效。

> 目录应为 `...\.workbuddy\skills\tweet-writer\SKILL.md`（`SKILL.md` 必须在技能文件夹顶层，不要多套一层）。

### 方式二：下载 ZIP

仓库页 → **Code → Download ZIP** → 解压 → 把 `tweet-writer` 文件夹放进上面的 skills 目录。

### 方式三：项目级安装（团队共享）

放进项目的 `.workbuddy/skills/` 目录，随仓库共享给协作者。

## 💬 怎么用

装好后，用下面任意一句话触发：

```
@skill:tweet-writer 写推文 https://example.com/article
把这篇写成推文（附文章或链接）
发一条推，主题是 XXX
写条推特，要接地气、带表情、100 字以内
```

**输入**：一篇文章 / 链接 / 附件 / 一个话题
**输出**：一条 ≤100 字、带钩子和表情、可直接发布的中文推文

### 示例

> **素材**：一篇讲"AI 用旧卫星数据补出首张紫外全天图"的报道
>
> **产出**：
> ```
> AI 几天就能干完人几周的活，你的饭碗还稳吗？🤔
>
> 一个教授把拖了几十年的活丢给 Claude，几天就补齐了 1.19 亿颗星的紫外全天图，人只负责指方向。
>
> 剩下那些没人爱干的苦活，正在悄悄交给 AI💸
> ```

## 🔒 安全性

- **不联网、不读取文件、不访问凭证**
- 仅提供写作规则与范例，无任何副作用
