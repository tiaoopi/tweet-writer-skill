# 读图写推文参考：提取清单、角度映射、正反例

## 一、读图提取清单（看图时逐项过一遍）

| 类别 | 要提取什么 |
|---|---|
| 文字 | 标题、正文、标注、水印、时间戳 |
| 数字 | 金额、数量、涨跌、百分比、日期、ID |
| 人物 | 谁、什么身份、表情动作 |
| 场景 | 在哪、发生了什么 |
| 对话 | 聊天记录的关键几句原话 |
| 图表 | 坐标轴、趋势、极值、异常点 |
| 情绪 | 图整体传递的情绪（荒诞/心酸/搞笑/震惊） |

**底线**：只写图里看得到的。看不清、读不出关键信息时，先问用户，别脑补。

## 二、图 → 钱味角度映射

| 图片类型 | 可往"钱"上靠的角度 |
|---|---|
| 工资条 / 收入截图 | 收入与付出落差、行业真相 |
| 账单 / 负债截图 | 怎么欠上的、以贷养贷、被坑 |
| 报价 / 合同截图 | 隐藏成本、法律陷阱、被割 |
| 数据图表 | 行业暴富 or 暴雷、趋势背后的钱 |
| 聊天记录 | 借钱、担保、跑路、诈骗套路 |
| 商品 / 广告海报 | 智商税、溢价、营销话术 |
| 招聘 / 裁员截图 | 打工生存、35 岁危机、裁员套路 |

图和政治/色情强相关时：向用户说明并建议换角度，不硬写。

## 三、正反例

**❌ 反例（书面、无钩子、不换行、信息堆砌）：**
> 从图中可以看到一份工资条，显示某人月收入为 8000 元，扣除五险一金后实发 6200 元，反映了当前部分行业的薪酬状况。

问题：不是提问、书面腔、没换行、没表情、把信息全堆上没重点。

**✅ 正例（≤100 字）：**
> 月薪 8000，到手 6200——这中间的钱都去哪了？🤔
>
> 一张工资条把打工人看破防了：五险一金扣完，房租水电再一交，一个月基本白干。
>
> 你以为挣得少是因为不努力？💸

好在：图里数字全用到、钩子是反问、口语唠嗑、有换行、表情克制、只讲"钱去哪了"一个点。

## 四、收尾标签（可选，默认不带）+ 索要互动禁令

### ⛔ 第一优先：禁止索要互动

图里的求互动话术（截图里带"扣 1""互关必回""求关注"的），**不要转述进推文**：

> 扣 1 / 评论区报个数 / 我去你主页回访 / 条条必回 / 互赞互回 / 关注我 / 求转发 / 看到必回

原因：X 判为 **spam / 平台操纵**，会给账号打"临时标签"，**触达被排除出推荐、搜索、回复区、趋势**（已有大量真实案例）。**改成内容型提问**即可：把"来我评论区"换成"你怎么看这件事"。

### 标签：可选、默认不带

默认**不输出**标签行。仅当用户明确要求时才挑 **1 个**：

| 系别 | 备用标签 |
|---|---|
| 蓝V系 | `#蓝V互关` `#蓝V互助` `#蓝V交朋友` |
| 内容系 | `#AI搞钱` `#AI工具` `#程序员日常` `#搞钱思路` `#职场观察` `#副业笔记` |
| 交友系 | `#真诚交友` `#浇朋友` |

⛔ **已停用**：`#互关必回` `#互赞互关` `#互关互助` `#涨粉互助` `#互关走一波` `#抱团互助`

## 五、输出前最后一步

把推文和图片**并排再核一遍**：图里的数字/事实有没有用错？有没有编造？钩子够不够勾人？字数够短吗？表情克制吗？有没有"索要互动"的话术（有就删）？——全过再交稿。
