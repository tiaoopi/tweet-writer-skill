# 读图写推文参考：提取清单、角度映射、正反例

## 一、读图提取清单（看图时逐项过一遍）

| 类别 | 要提取什么 |
|---|---|
| 文字 | 标题、正文、标注、水印、时间戳 |
| 数字 | 金额、数量、涨跌、百分比、日期、ID |
| 人物 | 谁、什么身份、表情动作 |
| 场景 | 在哪、发生了什么 |
| 对话 | 聊天记录的关键几句原话 |
| 图表 | 坐标轴、趋势、极值、异常点 |
| 情绪 | 图整体传递的情绪（荒诞/心酸/搞笑/震惊） |

**底线**：只写图里看得到的。看不清、读不出关键信息时，先问用户，别脑补。

## 二、图 → 钱味角度映射

| 图片类型 | 可往"钱"上靠的角度 |
|---|---|
| 工资条 / 收入截图 | 收入与付出落差、行业真相 |
| 账单 / 负债截图 | 怎么欠上的、以贷养贷、被坑 |
| 报价 / 合同截图 | 隐藏成本、法律陷阱、被割 |
| 数据图表 | 行业暴富 or 暴雷、趋势背后的钱 |
| 聊天记录 | 借钱、担保、跑路、诈骗套路 |
| 商品 / 广告海报 | 智商税、溢价、营销话术 |
| 招聘 / 裁员截图 | 打工生存、35 岁危机、裁员套路 |

图和政治/色情强相关时：向用户说明并建议换角度，不硬写。

## 三、正反例

**❌ 反例（书面、无钩子、不换行、信息堆砌）：**
> 从图中可以看到一份工资条，显示某人月收入为 8000 元，扣除五险一金后实发 6200 元，反映了当前部分行业的薪酬状况。

问题：不是提问、书面腔、没换行、没表情、把信息全堆上没重点。

**✅ 正例（≤100 字）：**
> 月薪 8000，到手 6200——这中间的钱都去哪了？🤔
>
> 一张工资条把打工人看破防了：五险一金扣完，房租水电再一交，一个月基本白干。
>
> 你以为挣得少是因为不努力？💸

好在：图里数字全用到、钩子是反问、口语唠嗑、有换行、表情克制、只讲"钱去哪了"一个点。

## 四、互关标签池（收尾用，换着来）

收尾标签意思都是"愿意互看、交个朋友"，**字样要灵活**：同一条 1~2 个，**不同条换不同组合**，别每条都挂同一对。

| 系别 | 备选标签 |
|---|---|
| 蓝V系 | `#蓝V互关` `#蓝V互关互助` `#蓝V交朋友` `#蓝V互助` `#蓝V互关涨粉` |
| 交友系 | `#真诚交友` `#交个朋友` `#浇朋友` `#互关交友` `#交友互助` |
| 互助系 | `#互关互助` `#互关必回` `#互赞互关` `#报团取暖` `#抱团互助` |
| 起号系 | `#新人起号` `#起号互助` `#涨粉互助` `#冷启动互助` `#互关走一波` |

配法：挑两个不同系别组合（`#蓝V互关 #真诚交友`、`#互关必回 #浇朋友`…），**别总用同一对**；也可只带 1 个。标签行不占正文字数。不堆 4 个以上，也不写"互赞必回 秒回"这类硬求互动的字样。

## 五、输出前最后一步

把推文和图片**并排再核一遍**：图里的数字/事实有没有用错？有没有编造？钩子够不够勾人？字数够短吗？表情克制吗？结尾标签是否换了新的一组？——全过再交稿。
