# Image Tweet Writer（读图写推文）

## Overview

用户丢来一张图（截图 / 海报 / 图表 / 聊天记录 / 文章截图），看懂它，然后写出一条 **≤100 字**、可直接发布的中文推文。核心：**先读图看懂 → 揪出图里最戳人的一个点 → 用一句勾人的问题开头、像唠嗑一样讲出来**。

## 何时使用

- 用户发来图片（含图片路径）+ "写推文/写条推/读图写推"
- 用户发来海报、数据截图、聊天记录截图，要求配文案发推特
- 用户说"这图能写个什么推""照这张图发一条"
- 用户发来一张推文截图并说"复刻"——此时**必须换词复刻**：保留原文的骨架（结构/节奏/语气/梗），但所有措辞都要换成自己的说法，文字重叠参照 tweet-rewriter 的 ≤30% 标准，禁止照抄原句。开场词、关键名词、结尾问句一律换说法。

## 硬性规则（必须全部满足）

1. **必须先读图**：未用读图工具看清图片内容前禁止动笔。要识别图里的：标题/正文文字、关键数字、人物、场景、对话、表格数据。**禁止编造图中没有的信息**；图中信息不足以支撑推文时，先向用户确认。
2. **字数 ≤ 100 字**：统计中文汉字 + 数字 + 标点（表情不计但整体要短）。写完自查，宁短勿长。
3. **开头是一句"诱惑性问题"**：第一行用反问/设问，让人觉得"这我有话说 / 想反驳 / 想知道下文"，带一点反常识或悬念。
4. **语气接地气、真实**：像跟朋友唠嗑（"这哥们""说实话""结果呢"），拒绝书面腔、宣传腔、AI 腔。
5. **排版有呼吸感**：2~3 段、段间换行；每行别太长，手机上一眼扫完。
6. **表情符合推特大众习惯，且必须轮换**：常见且克制，1~3 个，放句尾或行尾，不堆砌。**同一条内不重复，连续几条也别老用同一个**——尤其别把 🤔 💸 😂 当固定搭配。按"情绪功能"换着挑：

   | 功能 | 可换的表情 |
   |---|---|
   | 疑惑 / 反问 | 🤔 🤨 🧐 🙃 😅 |
   | 钱 / 亏 | 💸 💰 📉 🧾 🤑 |
   | 苦笑 | 😂 🤣 😆 😹 |
   | 无奈 / 叹气 | 😮💨 🫠 😶 😑 |
   | 震惊 | 😲 🤯 😳 |
   | 惨 / 心碎 | 😭 🥲 💔 😩 |
   | 犀利 / 围观 | 👀 🔍 ⚡ 🎯 |
   | 加劲 / 燃 | 🔥 💪 🚀 ✨ |
   | 收尾 / 佛系 | 🍵 😴 🌙 🚬 |
7. **只讲一个核心点**：≤100 字塞不下全部，选图里最扎心/最反直觉的那一点放大。
8. **守红线、优先谈钱**：政治、色情尽量少讨论；图里若含钱味（搞钱、亏钱、负债、被坑、报价、收入），就往钱上多写。图若以政治/色情为核心，说明并建议换角度，不硬写。
9. **收尾合规铁律：禁止索要互动，标签改为可选**（X 会将这类行为判定为 spam / 平台操纵，导致账号被打"临时标签"，触达被排除出推荐、搜索、回复区、趋势）：

   - **禁止任何明示索取互动的话术**——不写"扣 1""评论区报个数""我去你主页回访""逛后感必回""条条必回""互赞互回""关注我""求转发""看到必回"等**要求读者点赞 / 关注 / 评论 / 回访**的句子。一个字都不要出现。
   - 想催互动，只能靠**内容本身**：抛一个真想让人反驳的问题、给一个低成本二选一。**不能明说要人回。**
   - **互关标签改为"可选、默认不带"**：默认**不输出**标签行；只有用户明确要求带标签时才加，且**最多 1 个**，别每条都带、别总用同一个。标签行不计入字数限制（100 字只算正文）。

| 系别 | 备用标签（仅在用户明确要求时挑 1 个） |
|---|---|
| 蓝V系 | `#蓝V互关` `#蓝V互助` `#蓝V交朋友` |
| 内容系 | `#AI搞钱` `#AI工具` `#程序员日常` `#搞钱思路` `#职场观察` `#副业笔记` |
| 交友系 | `#真诚交友` `#浇朋友` |

> ⛔ **已停用的标签**：`#互关必回` `#互赞互关` `#互关互助` `#涨粉互助` `#互关走一波` `#抱团互助` ——凡带"必回""互赞""涨粉""走一波"字样的一律不用。

## 工作流程

1. **读图**：用读图工具打开图片，逐项提取——文字（标题/正文/标注）、关键数字、人物与场景、对话或表格数据。
2. **找点**：从图中挑出最戳人的一个细节（一个数字、一句原话、一个反差、一个荒诞场景）。
3. **定角度**：优先往"钱"上靠（搞钱 / 亏钱 / 负债 / 被坑）。图不带钱味时，找"利益 / 收入 / 损失 / 套路"的切面切入。
4. **写钩子**：围绕该点设计一句能勾好奇、引发讨论的开头提问。
5. **写正文**：口语把细节讲清，制造反差或扎心感，结尾可留半开放结尾或抛问。
6. **控字数**：数一遍，超 100 字就砍（砍修饰、砍并列、砍重复）。
7. **过红线 + 排段加表情**：政治/色情自检 → 按规则 5、6 调整格式。
8. **收尾合规自检**：按规则 9 过一遍——有没有"扣 1 / 必回 / 求关注 / 求转发"这类**索要互动**的话术？有就删干净。标签**默认不带**，用户明确要求时才带 1 个。

## 自检清单

- [ ] 图片读完整了吗？有没有编造图中没有的信息？
- [ ] 全文 ≤ 100 字？
- [ ] 第一行是勾人的问题吗？
- [ ] 有没有 2~3 段、有换行？
- [ ] 语气像唠嗑吗？
- [ ] 表情 1~3 个、够大众，且**没和上一条重样**（别老是 🤔💸）？
- [ ] 只讲了**一个**核心点吗？
- [ ] 话题能沾钱时，是否优先往钱上写？
- [ ] 是否尽量少讨论了政治与色情？
- [ ] 有没有"扣 1 / 必回 / 求关注 / 求转发"这类**索要互动**的话术？（有就删）标签是否默认没带、只在用户要求时带 1 个？

## 相关技能

- `tweet-writer`：从零按固定风格写推文（无图）。
- `tweet-rewriter`：照着某条原文的风格仿写。
- 本技能：**输入是图片**，先把图看懂再写。
