# Tweet Rewriter（仿写推文）

## Overview

给它一段原文（文章、推文、帖子、段落），产出一条**意思不变、风格神似、但措辞全新**的推文。核心是三步：**读透原文 → 拆出它的"抓人手法" → 用自己的话照着重演一遍**。仿的是风格，不是抄句子。

## 何时使用

- 用户给一条推文/一段文字/一篇文章，说"仿写""照这个风格""模仿这条""改写成推文"
- 用户要求保留原意但换一种说法，用于自己的账号发布
- 用户说"这条很火，帮我照这个感觉写一条"

## 硬性规则（必须全部满足）

1. **必须先读原文**：未完整读取原文前禁止动笔；禁止编造原文没有的事实、数字、案例。
2. **意思不变**：主题、关键事实、数字、结论、情绪立场都必须与原文一致，不得歪曲、夸大或夹带私货。
3. **仿风格、不抄句子，重合 ≤ 30%**：模仿的是**换行节奏、说话口气、抓眼球的写法**，措辞必须用自己的话重写。两条硬线——
   - **单句**：禁止连续照搬原文超过 10 个字；
   - **整体**：仿写版与原文的**文字重叠（连续相同字串，剔除数字、标点与专有名词）不得超过原文的 30%**。数字（如 4305、10121）和不可替换的专有名词不计入重合。
   - 估算方法：把两版都去掉数字/标点，肉眼比对逐句相同或近乎相同的片段，重合字数 ÷ 原文总字数 > 30% 就整段换措辞重写。
4. **抓眼球手法要还原**：如果原文用悬念开头、反差、数字冲击、金句收尾、结尾抛问题等手法，重写版要保留同类手法（内容可以换表达）。
5. **表情符合推特大众习惯**：用推特常见、克制的那几个（🤔 😂 😅 😮💨 💸 🔥 😭 👇 …），一般 1~3 个，放在句尾或行尾，不堆砌。
6. **长度合适**：默认贴近原文篇幅；原文过长则压缩为一条推文能装下的长度（中文 ≤ 140 字 / 半角 280 字符），并按"留最戳人的一个点"裁剪。
7. **守红线**：政治、色情尽量少讨论；只要能沾上"钱"（搞钱、亏钱、负债、被坑），就往钱上多写。若原文核心是政治/色情敏感内容，向用户说明并建议换角度，不硬写。
8. **互关标签收尾（铁律，但必须换花样）**：重写完成后，**必须另起一行**附互关/交友类话题标签收尾，一般 1~2 个。**禁止每条都固定用同一组**——按内容气质从下方"标签池"里挑，**并尽量与上一条不同**：

| 系别 | 可选标签（每个系挑 1 个） |
|---|---|
| 蓝V系 | `#蓝V互关` `#蓝V互关互助` `#蓝V交朋友` `#蓝V互助` `#蓝V互关涨粉` |
| 交友系 | `#真诚交友` `#交个朋友` `#浇朋友` `#互关交友` `#交友互助` |
| 互助系 | `#互关互助` `#互关必回` `#互赞互关` `#报团取暖` `#抱团互助` |
| 起号系 | `#新人起号` `#起号互助` `#涨粉互助` `#冷启动互助` `#互关走一波` |

组合建议：「蓝V系 / 互助系」各挑一个搭配，两条之间别同质；内容很素时只带 1 个也行。**同一组标签不要连着用两次以上。** **标签行不计入字数限制**，140 字只算正文。

## 工作流程

1. **读原文**：完整读取，弄清"它说了什么"（事实与观点）。
2. **拆风格**：逐项拆解——
   - 换行/分段节奏（几段、每段多长、有没有短句独立成行）
   - 说话口气（犀利吐槽 / 幽默自嘲 / 冷静陈述 / 情绪化发泄）
   - 抓眼球手法（开头钩子类型、反差结构、数字用法、金句、结尾互动）
   - 人称与视角（第一人称亲历？旁观转述？对话式？）
3. **提核心**：一句话概括原意 + 列出必须保留的关键事实/数字。
4. **重写**：按拆出的风格模板，用自己的话重演一遍；表达换血、骨架照搬。
5. **自检**：意思一致吗？风格像吗？有没有整句照搬？**与原文重叠字数是否 ≤ 30%？**表情合适吗？长度合适吗？

## 仿写自检清单

- [ ] 原文读完整了吗？有没有编造？
- [ ] 意思、关键数字是否与原文一致？
- [ ] 有没有连续 10 字以上照搬原句？
- [ ] **与原文重叠字数是否 ≤ 30%**（数字、标点、专有名词不计）？
- [ ] 换行节奏和原文像不像？
- [ ] 口气（吐槽/冷静/幽默）还原了吗？
- [ ] 抓眼球手法（钩子/反差/数字/金句）保留了吗？
- [ ] 表情是否 1~3 个、够大众？
- [ ] 长度是否适合发推（≤140 中文字）？
- [ ] 是否守了红线（少谈政治色情、沾钱多写钱）？
- [ ] 结尾是否另起一行带了互关标签，且**换了一组**（不是每次都 `#蓝V互关互助 #蓝V交朋友`）？
