# 仿写推文参考：风格拆解、抓眼球手法、正反例

## 一、风格拆解清单（读原文时逐项过一遍）

| 维度 | 要拆什么 | 示例问句 |
|---|---|---|
| 换行节奏 | 几段？每段几行？有没有一句话独占一行？ | 它是不是"钩子一行 / 故事一段 / 金句一行"？ |
| 口气 | 吐槽？冷静？幽默？情绪化？ | 像在骂街、唠嗑，还是在讲道理？ |
| 人称视角 | 第一人称亲历 / 旁观转述 / 对话式 | 是"我有个朋友"还是"直接开怼"？ |
| 抓眼球手法 | 悬念开头 / 反差 / 数字冲击 / 金句 / 结尾抛问 | 第一句靠什么让人停下来？ |
| 词汇风格 | 口语词？网络梗？专业术语？ | 有没有"好家伙""绷不住"这类词？ |

**骨架照搬、表达换血**：结构可以一样，但每个句子的措辞都要重新说。

## 二、常见抓眼球手法对照（原文用什么，重写就保留什么）

| 手法 | 原文长这样 | 仿写保留的是 |
|---|---|---|
| 悬念反问开头 | "你以为 X？其实……" | 依然用反问开头，问题可以换个问法 |
| 数字冲击 | "月入 1 万，负债 115 万" | 保留数字本身，换叙述方式 |
| 反差打脸 | 先立常见认知，再推翻 | 保留"立—破"结构 |
| 金句收尾 | "只能说，好自为之" | 结尾留一句类似分量的短句 |
| 结尾抛问 | "换你怎么选？" | 保留互动式收尾 |

## 三、红线

- 政治、色情**尽量少讨论**：原文若以这两类为核心，向用户说明并建议换角度，不硬写。
- 沾钱就多写钱：搞钱 / 亏钱 / 负债 / 被坑是中文区流量密码，能用就用。
- 防搬运（两条硬线）：
  - **单句**：连续 10 字以上照搬原句 = 抄袭，整句换措辞。
  - **整体**：仿写版与原文**文字重叠 ≤ 30%**（剔除数字、标点、专有名词后估算；重合字数 ÷ 原文总字数）。数字（4305、10121 这类）必须保留原样，但不算重合。
- 降重合度的常用手法：换同义词（逛→转、报数→晒数据）、换句式（主动↔被动、长句拆短）、换连接词（但→不过、恰恰→偏偏）、保留数字但重排叙述顺序。

## 四、正反例

**原文（供参考）：**
> 几周的活，AI 几天就干完了。你的饭碗还稳吗？🤔
>
> 一个教授把拖了几十年的活丢给 Claude，几天就补齐了 1.19 亿颗星的紫外全天图，人只负责指方向。
>
> 剩下那些没人爱干的苦活，正在悄悄交给 AI💸

**❌ 反例（整段照抄，只是小改）：**
> 几周的活 AI 几天就干完了，饭碗还稳吗🤔
> 教授把活丢给 Claude，几天补齐 1.19 亿颗星的全天图，人只负责指方向。

问题：句式几乎照搬，没有换血；手法没升级，等于搬运。

**✅ 正例（同意思、同风格、措辞全新）：**
> 科学界拖了几十年没人干的活，现在 AI 抢着干了🔥
>
> 一位天体物理学家随手把任务扔给 Claude，几天后：1.19 亿颗星的紫外全天图出炉，教授全程在忙别的项目。
>
> 你猜人在这件事里还剩什么活？🤔

好在：意思一致、数字保留、口语与换行节奏一致、结尾抛问呼应原文互动感，但每句措辞都是新的。

## 五、互关标签池（收尾用，换着来）

收尾标签意思都是"愿意互看、交个朋友"，但**字样要灵活**：同一条 1~2 个，**不同条换不同组合**，别每条都挂同一对（像机器人、也容易被判重复）。

| 系别 | 备选标签 |
|---|---|
| 蓝V系 | `#蓝V互关` `#蓝V互关互助` `#蓝V交朋友` `#蓝V互助` `#蓝V互关涨粉` |
| 交友系 | `#真诚交友` `#交个朋友` `#浇朋友` `#互关交友` `#交友互助` |
| 互助系 | `#互关互助` `#互关必回` `#互赞互关` `#报团取暖` `#抱团互助` |
| 起号系 | `#新人起号` `#起号互助` `#涨粉互助` `#冷启动互助` `#互关走一波` |

配法：挑两个不同系别组合（`#蓝V互关 #真诚交友`、`#互关必回 #浇朋友`、`#新人起号 #报团取暖`…），**别总用同一对**；也可只带 1 个。标签行不占正文字数。不堆 4 个以上，也不写"互赞必回 秒回 关注我"这类硬求互动的字样。

## 六、输出前最后一步

把重写版和原文**并排读一遍**：意思一样吗？风格像吗？句子不一样吗？**重叠字数 ≤ 30% 吗？**结尾标签是否换了新的一组？五项都过，再交稿。
